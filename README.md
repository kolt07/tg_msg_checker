# Аналіз повідомлень

Локальний модуль: пачка повідомлень проходить лексичний пошук словоформ і детектор координат. У відповіді лишаються лише повідомлення, де щось знайдено: теги словників і сутності.

Ядро в `backend/tg_msg_checker` не залежить від FastAPI.

## Запуск

Бекенд:

```powershell
cd backend
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
py -m uvicorn app.main:app --reload --port 8000
```

Фронтенд (потрібен Node.js):

```powershell
cd frontend
npm install
npm run dev
```

Інтерфейс: `http://127.0.0.1:5173`. Запити `/api` проксуються на порт 8000.

Docker Compose піднімає обидва сервіси. Словники пишуться в `backend/data` на хості.

```powershell
docker compose up --build
```

Інтерфейс: `http://127.0.0.1:8092`. API: `http://127.0.0.1:8030`. Змінні `COORD_CRS` і `WORKERS` можна задати в оточенні перед запуском.

## API

`POST /api/analyze`

```json
{ "messages": [{ "id": "1", "text": "бачив гранату, X = 5179365 Y = 6500127" }] }
```

Відповідь — масив. Повідомлення без тегів і сутностей не входять до нього. Час обробки на сервері — заголовок `X-Elapsed-Ms`.

Словники: `GET/POST /api/dictionaries`, `PUT/DELETE /api/dictionaries/{id}`.

Слово зберігається в називному відмінку. Мова словника: `uk`, `ru` або `en`. Фраза — до 4 слів. Під час збереження слово розгортається у словоформи, пошук іде автоматом Ахо–Корасік.

## Сутності

Координати: десяткові градуси, DMS, DDM, UTM, MGRS і прямокутні 6-градусні Гауса–Крюгера. Пріоритетний запис: `X = 5179365 Y = 6500127` (`X` — північ, `Y` — схід із номером зони). Пара через кому, наприклад `5158697, 6485198`, теж приймається, якщо проходить ту саму перевірку. Датам за замовчуванням СК-42 (`COORD_CRS=sk42` або `usk2000`). Точка перевіряється як координата земної поверхні.

Пачки до 4 повідомлень або до 32 КБ обробляються в процесі запиту. Більші йдуть у пул процесів. Кількість воркерів: `WORKERS` (за замовчуванням `min(4, cpu)`).
